# Indian library validation results

Snapshot: 2026-11-15T08:05:13.910Z. Re-run the summary tool after updating evidence.

**Frozen cohort: 48/50 institutions have ten verified books.** 19 additional entries have ten. The size-led cohort is not an exact national ranking; [selection and sources](ranking-notes.md) explain the limits.

Across wider checks, **612 additional directory entries have at least one verified book**, out of 848 actually attempted and 1168 reviewed. This includes the additional ten-book entries. These are catalog connections; branches and uncertain duplicate institutions must not be presented as a unique-library census. Deferred members of a blocked host are excluded from the attempted count.

A pass requires an explicit matching query, a resolved record with matching title, and a live app answer in one complete attempt. Ten must pass on one route. Failed attempts, cold ISBN checks, cache conditions, non-book exclusions, and endpoint diagnostics remain in the [source evidence](README.md). A holding does not necessarily mean a borrowable copy.

## Inspecting or updating results

[coverage.csv](coverage.csv) provides a sortable row for every reviewed connection. [summary.json](summary.json) links each counted record to its original evidence files and lists all reviewed entries, including those with no verified books. The source files preserve failures and timing. No stored answer, periodical, title-only guess, or other institution's record can satisfy the count.

Run from the repository root:

```sh
node --test tools/catalog-hardening/*.test.mjs
node tools/catalog-hardening/summarize.mjs
```

See [methodology and reproduction](README.md) before sending live requests. Changes are on a branch excluded from Vercel deployments; this audit is not a deployment.
