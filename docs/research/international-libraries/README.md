A reserve may have a valid book response but insufficient size evidence, partial/test coverage or an access restriction. UMT (Pakistan) and UAAAN (Mexico) are policy-excluded historical observations: do not replay their catalog requests. Both machine-readable indexes flag these observations. Institution counts differ from distinct catalog endpoints and request counts, especially for union catalogs. Book ownership, current circulation, reader eligibility and automated-access policy remain separate findings.

Exact requests, timestamps, returned records, source sizes, access limits and raw or explicitly redacted response evidence are linked from each country dossier. The query inventories preserve related-title results and unresolved identifiers. Captured UNAM Aleph session links are transient; use its documented fresh-session recipe.
