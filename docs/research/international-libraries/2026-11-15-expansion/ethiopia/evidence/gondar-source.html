Automation System

  • Home
  • Automation System

Library automation system handles the various functions of the University of Gondar library. It provides a complete solution to the library management. At the University of Gondar, library automation is based on RFID System. All library collections are tagged by RFID chip. Almost all sections of the library have automated.

Features of library automation at the University of Gondar library

  • Integration of all records of students
  • It can manage the safety of the collections
  • Manage the records systematically
  • It can track any information online
  • One can generate the reports
  • Manage all information online
  • Easy to maintain records
  • It leads to fast book entry

OPAC

You can access all the record of the library through OPAC (10.139.5.18)
