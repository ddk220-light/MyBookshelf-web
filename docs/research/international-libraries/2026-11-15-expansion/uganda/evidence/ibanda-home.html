Welcome to Ibanda University Library OPAC

Discover, search, and access the knowledge resources of Ibanda University Library.

📚 Library Catalogue

Search the library catalogue using the search box above to find books, journals, theses, and other academic materials available in the library.

🔎 Advanced Search

Use the Advanced Search option to refine your search using author, title, subject, keyword, or publication year.

👤 Library Account

Log in to your library account to renew borrowed books, reserve materials, create resource lists, and track your transactions.

💡 Smart Library Features

Enjoy modern library services such as book reservations, tagging, user reviews, and personalized reading lists.
