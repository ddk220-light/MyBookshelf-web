Home » University Library

Mission

The BukSU Library provides accessible information resources through updated collections and competent staff that are essential to instruction, research, extension and production.

Vision

The BukSU Library will be a primary partner in the development, provision and delivery of information resources and services.

Online Library

Curated resources for your access.

eBooks

A collection of more than 1,000 open access eBooks in more than 300 subject areas.

eJournals

A collection of Journal articles requested by patrons.

eThesis and Dissertation Abstracts

A collection of thesis and dissertation abstracts arranged by field of specialization.

Multimedia

A collection of videos in different subject areas.

What is OPAC?
  • An online public access catalog (often abbreviated as OPAC or simply library catalog) is an online database of materials held by a library or group of libraries. Users search a library catalog principally to locate books and other material available at a library.
  • The Library is using Follett Destiny Library Manager. DLM is an easy-to-use, web-based library automation and management solution that offers Integrated circulation, cataloging, searching, reporting and library management to help the library work more efficiently.
OPAC Homepage
How to Navigate OPAC
Destiny is a browser based program. For this reason you should not use the back button to return to a previously viewd page. Instead, use the bread crumbs. This is the trail created when you view pages and is located in the green bar at the top of the page.
Catalog
Searching with OPAC
Basic Library Search - This page allows you to search by Keyword, Title, Author, Subject, or Series. When you do a title search, omit articles like The, A, or And. For author, type in the last name then a comma and the first name.
Power Search
The Power search is great for narrowing your search. It allows you to link multiple search terms using Boolean logic.
