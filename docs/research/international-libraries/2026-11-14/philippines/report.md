# Philippines: library expansion research

Research checked **15 November 2026 UTC**. The parent artifact directory is dated 14 November. [Structured findings](findings.json) contain exact queries, POST bodies, HTTP status, timestamps, returned records and evidence paths. Raw HTML/JSON is retained in [evidence](evidence/) and [continuation evidence](continuation/evidence/). The earlier findings snapshot is preserved in [continuation](continuation/findings-before-replacement.json).

**Ten institutions are now recommended, with two public-library reserves. Twelve distinct institutions returned books across ten catalog endpoints; the selected ten use eight endpoints.** The selected ten are NLP, UP Diliman, USC, Ateneo de Davao, DOST-STII, MMSU, DSWD, CHED Central Office, Loyola School of Theology (LST), and AIIAS Leslie Hardinge Library. LST and AIIAS replace Imus and Butuan because official sources establish substantial collections; the two public libraries remain observed reserves.

**This is not a proven national largest-ten ranking or ten completed integrations.** DSWD and CHED collection ranks remain unproven, and several larger libraries remain blocked. Four institution scopes were verified through the same Philippine eLib union catalog; DOST-STII was additionally verified through ScINET and is counted once. LST's first book query and record read succeeded, but subsequent searches returned empty pages; its reliability remains unresolved. No institution was integrated into the application or cleared for production use.

The useful outcome is a mixed opportunity: Koha offers the fastest reuse, Follett offers the largest academic platform opportunity but substantial permission barriers, and two union catalogs offer broader discovery with important freshness limits.

## Marketplace and the biggest reusable opportunities

A March 2026 peer-reviewed study examined 312 accessible higher-education library websites/OPACs from 404 institutions initially identified using a CHED list. It found **89 Follett deployments (28.53%), 55 Koha (17.63%), and 12 TLC (3.85%)**. Another 93 had no *publicly accessible* LMS; this does not mean they had no internal library software. The results describe the study's visible academic sample, not a national installed-base census. Follett, rather than Koha, was the most common identified academic platform. [Balbin, *College & Research Libraries*, methods and Table 2](https://crl.acrl.org/index.php/crl/article/download/27268/35052).

The infrastructure opportunity is uneven access to existing collections and systems. It would be inaccurate to describe Philippine libraries uniformly as lacking infrastructure. Larger universities often have substantial commercial systems; some national and public services have accessible open-source catalogs, while others have local-only access, restrictions or connectivity failures.

## Large or potentially useful candidates that remain blocked

The negative evidence is local to this execution environment and time. A proxy failure is not evidence that an institution's catalog is down for its own users.

- **Silliman:** the old HTTP port 8080 route timed out. Continuation found the current [virtual library](https://www.sulibraryph.com/), linked by an [official SU announcement](https://su.edu.ph/news/su-library-goes-virtual-offers-online-services-activities/); it links to EBSCO Locate at `sulib.locate.ebsco.com`. Current robots disallows all crawling, so no search was sent. A 2013 [official report](https://su.edu.ph/news/985-software-for-personalized-mgt-of-lib-resources-launched/) describes over 250,000 volumes; this remains historical mixed scope, not a current count.
- **UP Los Baños:** Koha host returned a Cloudflare challenge. Its main library plus 11 units remain attractive; no search bypass was attempted.
- **Cavite State University:** Koha robots excludes search and details. Government-hosted institutional evidence reports 106,459 volumes / 92,199 titles, but the reporting date is unclear.
- **PUP NALLRC and Central Luzon State:** proxy connection failures, including robots 503. Policy status is unresolved, not equivalent to a missing robots file.
- **Quezon City Public Library:** the current custom site is reachable; `/search` is robots-disallowed. Old Koha endpoint assumptions are stale.
- **PNU, UE, MSU-IIT, VSU and Benguet:** current Follett catalogs explicitly disallow crawling. These support the platform opportunity but are not verified automated search successes.
- **DLSU Dasmariñas:** the official short link resolves to a Follett route, despite an older directory naming Koha; catalog/robots failed with proxy 503.
- **IRRI:** CloudFront explicitly blocks this environment's country. No alternate-region or other bypass was attempted.
- **Xavier/Ateneo de Cagayan:** official documentation identifies TLC and ALINet is a potential network lead; the linked library host returned 522. Current union holdings were not established.
- **National Museum:** Koha search returned HTTP 405 human-verification CAPTCHA; stopped. **La Union:** origin service-unavailable page. **University of Mindanao, San Agustin and CSPC:** catalog connection failures. **LibraryLink:** robots disallow all and forbidden home response.

## Implementation implication

Start engineering review with **MMSU and DSWD Koha**, and use Imus/Butuan as separately labeled public-library pilots. Fix MMSU's room-use-note interpretation first; offline replay found a real false impression of take-home availability. Replay other saved pages and verify edition matching, exact branch scope, negative results and production request budgets before adding any institution to the directory.

The next meaningful provider work is **TLC legacy PAC + LS2**, with observed collection access at USC, LST, Ateneo de Davao and AIIAS. LST requires reliability investigation before rollout; blank HTTP 200 responses must remain unknown. AIIAS also exposes some records that combine multiple publication years and ISBNs, so holdings must not be assigned to a single edition without evidence. Then consider **ScINET** and **eLib** for broader scientific/national discovery. ScINET exposes structured fields, but old inventory and differing call-number fields must remain visible as uncertainty. eLib needs institution attribution and a “listed in catalog, availability unknown” contract. Follett should be pursued through an authorized interface or library agreement. Continuation did not find a permissible machine-search path at any newly checked large deployment.

These results support a Philippines research/partnership track. They do not support a claim that ten nationally largest libraries are already ready for production integration.
