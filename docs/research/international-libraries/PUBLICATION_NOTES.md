# Git publication notes

All 30 country dossiers, source material, request evidence, inventories and review files are included. Generated Python caches are excluded by the repository ignore rules.

Before publication, temporary AWS-signed image query strings were redacted from the saved Nigerian ESUT homepage and record snapshots. This changes only image URL parameters; catalog titles, record identifiers and holdings remain intact. Original-response and retained-artifact hashes, byte counts and redaction notes are recorded in the corresponding request metadata and [redaction manifest](publication-redactions.json). Earlier documented source redactions remain labeled in their own evidence records.

The research conclusions remain 200 observed institutions/networks: 151 selected candidates and 49 reserves across 30 countries. No app integration or deployment is part of this branch.
