# Source catalog and connection options

Research date: 2026-10-31. Reconstructed for MyBookshelf-web; see [provenance](README.md#repository-transfer-and-evidence-provenance) and [historical API observations](evidence.json). Provider rules and quotas need rechecking before enabling a connector.

**Roles:** host supplies the reading destination; index describes items hosted elsewhere; resolver finds a location from an identifier. Some providers perform several roles.

**Effort:** low = documented search and straightforward mapping; medium = imports, XML, edition/access reconciliation or account setup; high = feed agreement or unresolved public integration. These are relative integration estimates, not delivery promises.

**Priority:** P0 = initial implementation; P1 = subsequent coverage; P2 = investigate or arrange access. No public API verified means this research did not establish one, not that none exists.

## 1. General ebooks and public-domain literature

| Source / role | How the app can search it | Reading destination and access distinction | Credentials, constraints, effort / priority |
| --- | --- | --- | --- |
| **Project Gutenberg — host** | Import official CSV/RDF catalog into local search; PG ID as identity. Official OPDS supports discovery. [Catalog formats](https://www.gutenberg.org/ebooks/offline_catalogs.html), [automation policy](https://www.gutenberg.org/policy/robot_access.html) | `https://www.gutenberg.org/ebooks/{id}`; metadata supplies HTML/EPUB/text format URLs. Public-domain status is generally US-specific; preserve per-record rights. | No key. Use approved catalog distribution, not website search scraping. Docs mentioned OPDS2 testing and planned XML feed retirement in 2027. RDF sample worked. **Medium / P0**. |
| **Gutendex — third-party Gutenberg index** | JSON `/books/?search=...&languages=en&topic=...`; MIME filters, `next` pagination, `/books/{id}`. [Docs and source](https://gutendex.com/) | `formats` map links to Gutenberg content; retain Gutenberg IDs and attribution. | No public-demo key. Docs recommend self-hosting for long-term use. Public query timed out. Consider its implementation instead of writing an importer; do not depend on its demo in production. **Low prototype, medium self-hosted / P1 alternative**. |
| **Standard Ebooks — host** | OPDS 1/2 `/feeds/opds`; public new-release RSS/Atom. [Feed rules](https://standardebooks.org/feeds) | Canonical ebook page and formats. Publisher-produced content is CC0; third-party material and public-domain jurisdiction need separate care. | Full feeds are a Patrons Circle/producer/sponsor benefit. Personal membership is not automatic permission to redistribute a catalog through an app. Confirm integration terms; new-release feed alone is incomplete. **Medium/high / P2**. |
| **Open Library — index linking to hosts** | `/search.json`, work/edition JSON; title, author, ISBN, language, ebook fields. [Usage rules](https://openlibrary.org/developers/api), [search](https://openlibrary.org/dev/docs/api/search) | Work/edition pages then a specific readable Archive item. Distinguish public scans, borrowing, previews and absent ebooks. Work-level `ebook_access` does not apply to every edition. | No key. Observed docs: 1 request/sec default, 3/sec with identifying User-Agent and contact. Cached user-driven discovery supported; high-traffic commercial backend use/bulk API harvesting discouraged. Use dumps/arrangement for scale. **Medium / P1 enrichment; already integrated**. |
| **Internet Archive — host/index** | Advanced Search JSON `/advancedsearch.php`; `/metadata/{identifier}`; search title/creator, media type and collection, then inspect access/files. [Developer portal](https://archive.org/developers/) | Prefer `https://archive.org/details/{identifier}`. `mediatype:texts` does not imply free reading: lending/restricted/metadata-only items exist. | Public metadata/search need no key. Inspect item access and rights; do not assume all uploads are rights-vetted. Search worked, item access validation remains. **Medium / P1**. |
| **Google Books — index/reader host** | `/books/v1/volumes?q=...&filter=free-ebooks`, `startIndex`; inspect `accessInfo`, `saleInfo`. [Usage](https://developers.google.com/books/docs/v1/using), [fields](https://developers.google.com/books/docs/v1/reference/volumes) | Returned `webReaderLink` or appropriate `infoLink`. Check full access, not previews or purchase offers. | Existing server key worked. Project-specific quotas; `accessInfo.country` is request context, not global access. Do not persist signed download URLs as identity. **Low/medium / P1 enrichment; already integrated**. |
| **Wikisource — host** | MediaWiki `action=query&list=search&srsearch=...`; resolve page IDs and full URLs. Separate language subdomains. [Search API](https://www.mediawiki.org/wiki/API:Search) | Stable text page. Editions, scans, transcriptions, proofreading and translations differ. Rights depend on text and contributions. | No key for public reads. Identify/cache requests, honor Wikimedia policy, filter namespaces/languages; scan index pages are not necessarily finished books. Search worked. **Low/medium / P1**. |

## 2. Scholarly books and chapters

| Source / role | Connection | Reading links, rights and limitations | Effort / priority |
| --- | --- | --- | --- |
| **DOAB — curated index** | Official JSON/CSV/KBART/MARCXML/ONIX; OAI-PMH `https://directory.doabooks.org/oai/request`. Import locally, update via datestamps and resumption tokens. [Metadata docs](https://doabooks.org/en/librarians/doab-metadata) | Metadata CC0; individual book licenses separate. Preserve full-text/publisher URLs, DOI/ISBN and fallback directory handles. `xoai` richer than simple Dublin Core; optional PRISM supplies peer-review metadata by DOI/ISBN. | No key for documented feeds. Harvesting is not interactive search. Identify, formats, ListRecords and one `xoai` record worked. **Medium / P1, first scholarly-book import**. |
| **OAPEN — host/library** | Official metadata exports or `https://library.oapen.org/oai/request`; local search. [Metadata docs](https://oapen.org/librarians/metadata) | Landing handles/download links; separate chapters and books. Some exports explicitly contain records without download links. Metadata CC0, content licenses vary. | No key for feeds. Overlaps DOAB: reconcile DOI/handle/ISBN and retain both sources. Only OAI Identify tested. **Medium / P1**. |

Do not display every chapter as a whole ebook. Link to a containing book only when the source provides that relationship.

## 3. Journal articles and broad scholarly discovery

| Source / role | Search/lookup | Reading and access handling | Credentials, limits, effort / priority |
| --- | --- | --- | --- |
| **DOAJ — journal/article index** | `/api/search/articles/{query}`, journal search, fields such as `bibjson.title`, page/pageSize. [API docs](https://doaj.org/api/v4/docs) | `bibjson.link` entries marked `fulltext`, usually publisher HTML/PDF. Journals are containers. Article coverage depends on metadata deposits. | No key for public read search; write APIs differ. Legacy-compatible route sample worked. Confirm supported version, quotas and metadata terms. **Low / P0**. |
| **OpenAlex — multidisciplinary index** | `/works?search=...&filter=is_oa:true`, filters/cursors, exact DOI lookup; `locations`, `best_oa_location`. [Authentication](https://help.openalex.org/api/authentication/), [costs](https://help.openalex.org/access/example-costs/) | Choose a suitable OA host landing page; optionally PDF. Record page/DOI alone is not proof of free reading. Inspect location OA, version, license and freshness. | Keyless first page worked. Observed policy: $0.10/day shared per IP keyless; verified free key $1/day; ordinary search $0.001/call; 10/30 RPS keyless/free. Cursor paging past first page requires key. Verify current policy and configured key. **Low/medium / P0**. |
| **Europe PMC — index/full-text platform** | REST `/webservices/rest/search?query=...&format=json`, `OPEN_ACCESS:Y`, `IN_PMC:Y`, `resultType=core`, cursorMark. [REST docs](https://europepmc.org/RestfulWebService) | Returned full-text locations/PMCID pages. OA filter is stricter than free reading; PMC inclusion does not imply an open reuse license. PubMed records alone need not be free. | No key for public REST. Parse individual access/license fields and observe service limits. OA query worked. **Low / P0**. |
| **PubMed / PMC — index / host** | NCBI E-utilities for bibliography; PMC OAI and OA services for archival metadata/eligible files. [PMC developers](https://pmc.ncbi.nlm.nih.gov/tools/developers/), [OAI](https://pmc.ncbi.nlm.nih.gov/tools/oai/) | Actual PMC articles at `https://pmc.ncbi.nlm.nih.gov/articles/{PMCID}/`; PubMed primarily bibliographic. Free reading and OA-subset reuse permissions differ. | Common E-utilities allowances are 3 requests/sec without key and 10 with key; verify current endpoint policy before coding. PMC endpoints have distinct rules. Prefer Europe PMC first to avoid duplication. **Medium / P1**. |
| **Crossref — DOI metadata index** | `/works?query.title=...`, `/works/{doi}`, filters/cursors. [REST docs](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) | DOI landing URLs, relations and licensing enrich records. A `link` or `license` field alone does not establish free reading. | Public reads without key; real `mailto` contact recommended for polite pool. Observe rate/concurrency headers. Search worked. **Low / P1 enrichment**. |
| **Unpaywall — DOI-to-OA resolver** | `GET https://api.unpaywall.org/v2/{doi}?email={contact}`. [API](https://unpaywall.org/products/api), [fields](https://unpaywall.org/products/api/v2) | `best_oa_location`, `oa_locations`, host/version/license/HTML/PDF. No OA result means not found by this resolver, not proof no free copy exists. | Real email required; observed docs said 100,000 calls/day. No DOI call tested without contact. Official site JS said title search retired 2026-09-18 (410), recommending OpenAlex. **Low / P1 resolver**, not search. |
| **Semantic Scholar — index/research graph** | Graph `/graph/v1/paper/search?query=...&fields=...`; DOI, citations, `openAccessPdf`. [API](https://www.semanticscholar.org/product/api) | Host PDF when supplied; record page is not necessarily full text. Citation graph optional. | Anonymous probe got 429; shared throttling. Key recommended; observed introductory keyed allowance 1 RPS. Check service license and commercial conditions. **Low/medium / P2**. |

Start with one broad index plus selected specialists. Calling OpenAlex, Crossref, CORE, Semantic Scholar and all repositories on every query would multiply duplicates, cost and latency.

## 4. Preprints, theses, repositories and reports

| Source / role | Connection | Access, identity and version handling | Credentials / priority |
| --- | --- | --- | --- |
| **arXiv — preprint host** | Atom/XML `https://export.arxiv.org/api/query?search_query=...&start=0&max_results=...`; title/author/category. [Manual](https://info.arxiv.org/help/api/user-manual.html), [terms](https://info.arxiv.org/help/api/tou.html) | Preserve ID and version, landing/PDF, preprint/publication status. Journal DOI is a relation, not license to substitute a journal article. [Licenses vary](https://info.arxiv.org/help/license/index.html). | No key. Current reviewed legacy API/OAI/RSS terms: one request/3 sec, one connection, across all controlled machines. Shared queue/cache needed. Atom worked. **Medium / P0**. |
| **bioRxiv / medRxiv — preprint hosts** | Official DOI/date-interval API `/details/{server}/{interval}/{cursor}`. [API](https://api.biorxiv.org/) | DOI, versions and supplied links; label preprints, especially medical material. Per-article licenses. | No public-endpoint key documented in reviewed material. Feed/lookup interface, not generic title-search replacement. Use aggregator coverage first or import date-window metadata. Docs reviewed; no query tested. **Medium / P1**. |
| **CORE — repository aggregator** | v3 `/search/works?q=...`; works/outputs/source/download URLs. [Service](https://core.ac.uk/services/api), [docs](https://api.core.ac.uk/docs/v3) | Reconcile copies and distinguish work from output; verify location access. Metadata/full-text rights are not one license. | Anonymous sample worked. Reviewed page described free unregistered access subject to terms; five single requests or one batch/10 sec; faster registered/enterprise access may cost and eligibility matters. **Medium / P1**, useful for theses. |
| **Zenodo — research host** | Public `/api/records?q=...&size=...`; filter resource type/access. [Docs](https://developers.zenodo.org/) | `links.self_html`, access_right, available files/license. Version DOI separate from concept DOI; embargoed/restricted records exist. | Anonymous reads worked; deposit authentication is separate. Sample was a dataset, so type filtering required. **Low/medium / P1**. |
| **HAL — repository host/index** | Solr-style `https://api.archives-ouvertes.fr/search/`, q/fq/field selection/JSON. [Search](https://api.archives-ouvertes.fr/docs/search) | `uri_s`, optional `fileMain_s`, DOI/version. Citation-only records exist; validate file-presence filter. | No-key query worked but sample lacked full-text field. **Low/medium / P1**. |
| **Shodhganga / university repositories — thesis hosts** | [Shodhganga](https://shodhganga.inflibnet.ac.in/), institution-specific DSpace/EPrints; discover advertised OAI endpoint/formats, import locally. CORE/OpenAlex can cover first. | Handles/PDFs when deposited/unrestricted; embargoes, language, rights and metadata-only records need per-record handling. | Homepage inspected; stable Shodhganga external API/OAI route and terms not verified. Do not assume every DSpace version shares one REST route. **High / P2 direct; P1 aggregated**. |
| **World Bank Open Knowledge Repository — report/book host** | [Repository](https://openknowledge.worldbank.org/); approved export/OAI/repository API after endpoint discovery; curated collection first. | Landing page/deposited file; reports/books/working papers have distinct versions/licenses. Institutional branding is not reuse permission. | Homepage retrieved; external search/bulk workflow not validated. **Medium/high / P2**. |

OAI-PMH is a metadata **harvesting**, not keyword-search, protocol. Standardize Identify/ListMetadataFormats/ListRecords/GetRecord, datestamps, deletions and resumption tokens. Still map each provider's fields, rights and full-text locations. Repository directories such as OpenDOAR help identify repositories but are not themselves a unified set of readable papers.

## Standard connection patterns

| Pattern | Examples | Shared implementation | Provider-specific work |
| --- | --- | --- | --- |
| REST/JSON search | DOAJ, Europe PMC, OpenAlex, Google, CORE, HAL | HTTP budgets/retries/response limits/paging | Query grammar, mapping, access, terms |
| Atom/XML search | arXiv | Safe XML and namespace parsing | Versions/query syntax/pacing |
| OPDS | Gutenberg, approved Standard Ebooks | OPDS 1/2 navigation/acquisition parsing | Feed permissions; not every feed supports text search |
| OAI-PMH | DOAB, OAPEN, institutions | Checkpoints, datestamps, resumption, deletions | Rich-field mapping, rights, locations |
| Bulk catalog | Gutenberg, DOAB/OAPEN, Open Textbook Library | Validation, staging, atomic index swap | Schema and allowed cadence |
| Identifier resolver | Unpaywall, Crossref | DOI normalization, lookup/cache | OA resolution vs bibliographic enrichment |
| Curated/partner feed | Children's and educational providers | Reviewed catalog/provenance/refresh | Permissions, coverage, audience/language fields |

No generic HTML scraper is needed for the first release. Search-engine scraping, subscription bypasses and unauthorized shadow libraries are excluded. Library-card services such as Libby/OverDrive and Hoopla belong to a separate entitlement/borrowing feature: free to a member is a different access promise.
