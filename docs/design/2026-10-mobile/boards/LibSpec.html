How library search works

One search box understands library names, short names, branch names, cities and postcodes. One tap finds what's near you, anywhere. Browsing by area and shared links cover the rest. Every result says what we can check there, so nobody chooses a library and then finds out it can't tell them anything.

Six ways in

1Type anything

Names first, then places. Matches library names, short names and aliases, and branch names. “Fremont” finds Alameda County Library through its Fremont branch.

“APCE”, “British Council”, “Fremont”, “600085”
2Near me

Works anywhere. Asks for location once, then sorts by the closest branch, not the head office. Distances use local units (miles in the US, km elsewhere), and approximate addresses read “about”.

Libraries nearby without a confirmed location follow the list, by city. Where we have no libraries, say so and offer browsing.
3A place

When a place is ambiguous, ask which one (Fremont, California or Fremont, Nebraska). Then show libraries within a radius. If there are none, widen it and say so.

“Nothing within 10 km. Showing the closest, 48 km away.”
4From a book

A book with no library yet has its own library search. Choosing one comes straight back to that book and checks it.

The book stays open the whole time.
5Browse by area

Country, then state, then district. For readers who know where they are but not the library's name.

7,071 libraries: India 6,686 · US 232 · Canada 132 · Japan 20 · New Zealand 1
6A shared link

mybookshelf.cloud/select/anna-centenary-library opens that library's card with one confirm button. It never switches silently, and keeps any book the reader was looking at.

Settings › Share your library makes the link.

What a result row says

aName as the library uses it. When two share a name, add the region (Richmond Public Library · California vs · British Columbia).
bWhere: city and region. Use the district when there's no city.
cSize: number of branches.
dWhat we can check: always one of the four levels on the right.
eDistance, only when the reader shared location or picked a place. To the closest branch, in local units.

Four levels of “what we can check”

Checks availability

We can say whether a copy can be borrowed. Some catalogs add copy counts, shelf location and call number. Large US systems say “available” for the whole system, not by branch.

Searches the catalog

We can find whether the library lists a book, but not whether it's on the shelf. Many college catalogs in India work this way.

Search on their website

The connection isn't built yet, or the catalog can only be searched on its own site, so we link there instead. Examples include VIT Chennai, Arul Anandar College and Atlantic County.

Plus a membership note

Added to any level when the library says borrowing needs membership or campus access, for example: “Membership rules apply.”

Edge cases to handle

  • Same name, different place. Two Richmond Public Library entries, one in California and one in British Columbia. Neither has a city or a location, so show the region and country on every row.
  • Searching by branch. When the match is a branch, show “Fremont branch of Alameda County Library”. Choosing it selects the system and remembers the branch to show first.
  • Nothing nearby. Widen the radius and say so. If nothing is near at all, say we don't cover the area yet and offer browsing by country.
  • No match at all. Suggest a shorter query, the town instead, or browsing by country.
  • Already chosen. Your library is pinned at the top with a check. It also appears in results with a check instead of “Choose”.
  • Switching libraries mid-book. Return to the same book and page, and re-check availability right away.
  • Names that aren't unique. “Stratford Public Library” appears twice in Stratford, Ontario: the library itself (6 locations) and a 1-location catalog that seems to be a shared Perth County one. “Sitka Library” appears twice with no place at all. Fix the names in the directory data. Until then, rows show the location count and catalog source.
  • Saved library disappears. If a saved library leaves the directory, keep the shelf, tell the reader once, and ask them to choose again.
