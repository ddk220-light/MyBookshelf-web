About MyBookshelf

MyBookshelf tells you whether your public library has a book, so you can borrow it instead of buying it. It's free, needs no account, and has no ads.

What we promise

  • Independent: not run by, paid by or affiliated with any library or bookshop.
  • Honest results: we say when we can't tell, and never guess that a book is missing.
  • Private by default: no account, no ads, no stored searches, location only when you ask.
  • Open: the code and the library list are public under Apache-2.0 and CC BY 4.0.
  • Respectful of libraries: we identify ourselves, keep requests light, and fix details on request.

How the library list is made

Each library comes from its own public website or catalog, checked by hand or by a published script. We record where each detail came from and when the catalog connection was last checked. [Link: how the directory works on GitHub]
