Site structure, sitemap and trust

Public pages are plain HTML built from the directory, readable without JavaScript. The app moves under /app and stays out of search. Every library is reachable in three clicks from the home page.

Addresses

mybookshelf.cloud
├─ /                         landing (static)
├─ /about  /how-it-works  /open-source  /privacy  /support
├─ /libraries                directory home: countries
│  ├─ /libraries/in                         country
│  │  ├─ /libraries/in/tamil-nadu           state or province
│  │  │  └─ /libraries/in/tamil-nadu/chennai   district or city (paged: ?page=2)
│  │  └─ …
│  └─ /libraries/anna-centenary-library     one library (flat slug, never nested)
├─ /libraries/search?q=      results for the landing form   noindex
├─ /app/…                    the app: shelf, search, book, libraries, settings   noindex
├─ /select/?next=      deep link: choose a library, then open Search   noindex
└─ /robots.txt  /sitemap.xml  /404

Sitemap index

/sitemap.xml                    sitemap index
├─ /sitemaps/pages.xml          landing, about, how it works, open source, privacy, support
├─ /sitemaps/areas.xml          every country, state and district page
├─ /sitemaps/libraries-in-1.xml   India, split every 10,000 URLs
├─ /sitemaps/libraries-us.xml
├─ /sitemaps/libraries-ca.xml
├─ /sitemaps/libraries-jp.xml
└─ /sitemaps/libraries-nz.xml

Only indexable pages are listed. lastmod is the date a library's details or catalog connection were last verified, never the build date. Each file stays under 50,000 URLs and 50 MB.

Indexed or not

indexLanding, site pages, area pages, libraries with a working catalog connection, or a verified place plus one more real fact
noindex, followThin library pages: published and linked, indexed once their data improves. Page 2+ of long areas stays indexable with its own canonical
noindex/app, /select, /libraries/search, /api

Every page has

A unique title and description · canonical URL on the apex domain · breadcrumb · JSON-LD (Library, BreadcrumbList, ItemList, Organization, WebSite) · Open Graph image · a real 404 for unknown paths · permanent redirects for renamed slugs.

Trust signals

Independence notice on every library page · GitHub link and licence in the footer · About with a real person and contact · source link for every address · “last checked” dates · no ratings, ads or invented stats · “Report a problem” opens a public GitHub issue · privacy page in plain words.
