# Contributing

Use Node 22 and npm workspaces. Run `npm ci`, `npm run typecheck:client`,
`npm run test:client`, `npm test --workspace=server`, and `npm run build`.
Run `npm run test:seo` after building; browser tests use Playwright.

For a library correction, include its name, the field, and an official source URL.
Do not include card numbers, PINs, access tokens, private contacts, or patron data.
Library listings must distinguish membership, catalog presence and borrowability.
Failed lookups are unknown, never evidence that a book is missing.

Contributions to original code use AGPL-3.0-only. Original directory contributions
use CC BY 4.0. Retain all third-party licence and source notices.
