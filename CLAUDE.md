# MyBookshelf web app

This is the active web source repository. Read AGENTS.md and docs/STATUS.md
first; docs/README.md indexes the recent analysis and design references.

Node 22, npm workspaces, React/Vite client and Express anonymous API (it also
uses a separate catalog store and anonymous log, never the account database.
The catalog store also keeps the optional name and email a reader leaves with a
library request or problem report, for 90 days, never linked to an account or
the log).
The app is one screen at mybookshelf.cloud (/) (the shelf, with search, scan,
library pop-up and side panel as overlays); old /app/shelf, /app/search,
/app/libraries and /app/settings links redirect to it. The app shows found / not found / couldn't check for the chosen
library, never copy counts, due dates, floors or shelf numbers.
Use README.md for commands. Run client/server tests, type checking, build, SEO
checks and browser journeys before releasing. Provider keys stay server-side.
Indian libraries are offered when finding a library only if
server/data/india-catalogs-listed.json lists them (a strictly verified book or an
e-Granthalaya audit that found books; generated by
tools/catalog-hardening/library-status.mjs; listed IDs stay when a later check
fails, except a blocked library; remove one by adding it to the file's `removed`
list with id, reason and date, and the generator never lists it again).
Unlisted IDs stay resolvable for readers who already chose one; libraries outside
India are not affected; shared/seo-libraries.json controls only public library
pages. Failed checks are logged in library_check_events (90 days) for manual review.
Indian libraries without a source state get one from
server/data/india-library-regions.json (tools/directory/india-regions.mjs): published
state, a single-state PIN or address evidence only, never a library's name. Never treat failed checks as absence or merge editions
for identity or availability from similar titles (search cards may group
same-title, same-author records for display only). Every library check and search-list mark is one
any-field search of the chosen library's catalog for a term (the book's main title, or the typed text);
a row with at least 80% of the title's words is a find, and the card lists the matching rows (owner
decision, 20 November 2026). Respect
catalog access restrictions and reduced motion.
Search text may be stored only in the anonymous operational log (no account ID,
IP or device identifier; 12 months, then totals). Never put it in URLs, browser
storage, platform logs or analytics, and never link any log to an account. A typed ISBN may appear in a
book page's address; it is the book's identity, not search text.
